## BitBus

A small application that runs in the background while you're working. Whenever a bus leaves UBC's Vancouver campus, a little pixellated version of it drives across the bottom of your screen.

<img width="1675" height="941" alt="bitbus" src="https://github.com/user-attachments/assets/b012f355-3858-439a-9dde-80418f2c2b83" />

If you want to give the bus a high-five, or perhaps unleash some bottled resentment you hold towards a particular route, you can kick the bus as it moves along. *I heard that kicking it relentlessly has some unprecedented effects on its health.*

Created using Python, Tkinter, and Translink's GTFS API.
